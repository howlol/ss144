# 🛰️ Space Station 14 — Autonomous OpenAI Crew Server & Web Surveillance Control Center (`NSS Saltern`)

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/howlol/ss144/blob/arena/01a101dd-ss144/SS14_AI_Station_Colab.ipynb)

Полноценный сервер и веб-центр наблюдения для **Space Station 14** (построенный на базе открытого исходного кода [`space-wizards/space-station-14`](https://github.com/space-wizards/space-station-14)), где **каждый член экипажа на станции — автономный ИИ-агент под управлением любого OpenAI-совместимого API**, искренне верящий, что он живой персонаж на борту станции **NSS Saltern**.

---

## ✨ Ключевые возможности

1. **Настоящая карта, прототипы и C#-интеграция Space Station 14 (`Content.Server`)**:
   - **C# Мод (`ss14_mod/Content.Server/AIStation/`)**:
     - `AiAgentComponent.cs` — ECS-компонент для каждого ИИ-персонажа (хранит личность, должность, цель смены, статус агента Синдиката, внутренний монолог и память).
     - `AiStationBridgeSystem.cs` — серверная `EntitySystem` внутри `Content.Server`, поднимающая HTTP/JSON-мост на порту `12120`, спавнящая реальных гуманоидов через `StationSpawningSystem`, создающая `Mind` и `JobRole`, управляющая передвижением через `NPCSteeringSystem`, дверями через `DoorSystem`, предметами через `HandsSystem` и речью/рацией через `ChatSystem`.
   - **Реальная карта станции `NSS Saltern` (`Resources/Maps/saltern.yml`) и оригинальные `.rsi` текстуры**:
     - 6 905 тайлов пола, 1 576 стен, 1 014 окон и решёток, 437 шлюзов с правами доступа отделов, **53 настоящие камеры наблюдения СБ**, **56 маяков отсеков**, **60 точек спавна должностей**, **2 656 интерактивных консолей, автоматов и предметов**, а также **1 004 оригинальных `.rsi` спрайта** из репозитория SS14.

2. **Полное управление через любой OpenAI-Compatible API (`/v1/chat/completions`)**:
   - Прямо в веб-браузере можно ввести **API Base URL Endpoint** (OpenAI, OpenRouter, Groq, Together, DeepSeek, локальный Ollama / vLLM / LM Studio) и **API Key**, выбрать модель и нажать **«Проверить подключение (Test API)»**.
   - Каждый из 14+ членов экипажа (Капитан, ГП, ГСБ, Офицер СБ, Детектив, Старший Инженер, Атмосферный техник, Главврач, Химик, Научный руководитель, Квартирмейстер, Бармен, Уборщик, Клоун — скрытый агент Синдиката) получает своё реальное окружение (комнату, координаты, видимых людей, оборудование, шлюзы, локальный чат и сообщения по рации) и принимает решения от первого лица.

3. **Система камер наблюдения (CCTV) без необходимости заходить через десктопный лаунчер**:
   - **🎥 Главная камера / Слежение (Follow-Cam)**: плавный рендеринг станции на HTML5 Canvas с настоящими `.rsi` спрайтами SS14, анимацией открытия/закрытия шлюзов, 4-направленными спрайтами персонажей в униформе их должности, облачками речи и мыслей.
   - **📺 Сетка 4х камер СБ (CCTV Matrix)**: одновременное наблюдение с 4 мониторов камер безопасности станции (Мостик, Очередь ГП, Восточный коридор, Клонирование или любые из 53 камер).
   - **🗺️ Тактический радар станции**: обзор всей станции NSS Saltern с маршрутами A*-навигации всех персонажей.

4. **Управление из браузера (Игрок / Режиссёр)**:
   - **🕹️ Взять персонажа под прямое управление (`WASD` + Клик мышью по карте и шлюзам + Рация/Чат)**.
   - **🔮 Внушить мысль (`Subconscious Whisper`)** в подсознание любого ИИ-персонажа с мгновенным вызовом LLM.
   - **🚨 Панель Режиссёра и Спавнер**: запуск событий (Красный/Синий/Зелёный код, Утечка плазмы, Сбой энергосети, Угроза Синдиката) и высадка новых ИИ-персонажей с кастомным промптом.

Откройте ноутбук **`SS14_AI_Station_Colab.ipynb`** в Google Colab:
