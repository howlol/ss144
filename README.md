# 🛰️ Space Station 14 — Полноценная Игра в Браузере, Режим Госта, Камеры и ИИ-Экипаж (OpenAI API)

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/howlol/ss144/blob/arena/01a101dd-ss144/SS14_AI_Station_Colab.ipynb)

Полноценный игровой сервер и веб-клиент **Space Station 14** (построенный на базе открытого исходного кода [`space-wizards/space-station-14`](https://github.com/space-wizards/space-station-14)), где:
- **Каждый член экипажа на станции — живой ИИ-агент под управлением любого OpenAI-совместимого API**, искренне убеждённый, что он сотрудник станции **NSS Saltern**.
- **Вы можете играть прямо из браузера в режиме отдельного игрока (`Playable Crew Mode`) или в режиме Призрака-Наблюдателя (`👻 Режим Госта / MobObserver`)** со стабильными **60 FPS**, без необходимости устанавливать десктопный лаунчер!

---

## 🎮 Игровые режимы и управление в браузере

В верхней панели доступны 3 режима:
1. **🎮 Играть за персонажа (`Playable Crew Mode`)**:
   - Нажмите **«➕ Создать своего игрока»** (выберите имя, должность, стартовый отсек и статус **Агента Синдиката**) или кликните по любому из 14 членов экипажа и нажмите **«🎮 Играть за него»**.
   - Управляйте персонажем, берите предметы в **Левую и Правую руку**, экипируйте снаряжение с пояса, стреляйте из лазерного оружия, оглушайте дубинкой, надевайте наручники, взламывайте шлюзы мультитулом/емагом, отжимайте двери монтировкой, стройте стены с помощью РСУ (RCD), лечите раненых и открывайте интерфейсы автоматов и консолей станции!
2. **👻 Режим Госта (`MobObserver / Ghost Mode`)**:
   - Свободный полёт сквозь любые стены, окна и заблокированные шлюзы.
   - **🌀 Телепорт (`Ghost Warp`)** к любому члену экипажа или в любой из 56 отсеков станции.
   - **⚡ Напугать экипаж (`Boo!`)** — мигнуть светом и напугать ближайших ИИ-персонажей в комнате.
   - **Вселение в персонажа** — кликните по любому члену экипажа, чтобы мгновенно вселиться в его тело!
3. **📹 Пост камер (`CCTV Quad Split-Screen`)**:
   - Одновременное наблюдение с 4 камер безопасности станции (из 53 камер СБ на борту `NSS Saltern`).

### ⌨️ Горячие клавиши Space Station 14 в браузере

| Клавиша | Действие в игре |
| :--- | :--- |
| **`W` `A` `S` `D` / Стрелки / ЛКМ** | Передвижение персонажа (или свободный полёт в режиме Госта) |
| **`X` (или `1` / `2`)** | Сменить активную руку (**Левая рука** ↔ **Правая рука**) |
| **`Z`** | Использовать предмет в активной руке (клаксон `ХОНК!`, аптечка, постройка/разбор стены `RCD`) |
| **`Q`** | Выбросить предмет из активной руки на пол станции |
| **`E` (или ЛКМ по объекту)** | Взаимодействовать с ближайшим шлюзом / поднять предмет с пола / открыть шкафчик или консоль |
| **`C`** | Переключить Боевой режим (**🛡️ МИР** ↔ **⚔️ БОЙ**: стрельба из лазеров/оружия, удары дубинкой/мечом) |
| **`ПКМ` (Правый клик)** | Открыть контекстное меню глаголов SS14 (`Осмотреть`, `Поднять`, `Атаковать`, `Взломать`, `Вселиться`) |
| **`G`** | Быстрое переключение в **👻 Режим Госта** и обратно в тело |
| **`M`** | Показать / скрыть **🗺️ Радар станции** |
| **`T`** | Сказать фразу вслух (локальный чат) |
| **`Y`** | Сказать в общую рацию станции (`;` префикс) |

## 🤖 Прямое подключение к OpenAI API (Browser-Direct + Server Engine)

Нажмите **«⚙️ API Модель (OpenAI)»** в правом верхнем углу и укажите:
- **API Base URL Endpoint**: `https://api.openai.com/v1`, `https://openrouter.ai/api/v1`, `https://api.deepseek.com/v1`, `https://api.groq.com/openai/v1` или локальный `http://localhost:11434/v1` (Ollama / LM Studio).
- **API Ключ (`Bearer Token`)** и **Название модели** (например, `gpt-4o-mini`, `deepseek-chat`, `llama-3.3-70b-versatile`).

Запросы отправляются **напрямую из вашего браузера и с сервера** — обходя любые прокси-ограничения облачных песочниц. Когда вы произносите фразу рядом с ИИ-персонажем или атакуете/лечите его, он **вне очереди** обращается к модели OpenAI API и сразу отвечает вам в своей роли!
