## 📖 Обзор проекта (Overview)

Данный проект предоставляет **готовый единый блокнот Google Colab (`Space_Station_14_AI_Server.ipynb`)** и полноценную кодовую базу для развертывания **реального игрового сервера Space Station 14** с автономным экипажем на базе искусственного интеллекта.

Любой игрок может подключиться к серверу через официальный лаунчер **Space Station 14** и оказаться на одной станции с 20-40 уникальными ИИ-персонажами, которые живут своей жизнью, общаются, работают в отсеках и плетут заговоры.

### ✨ Ключевые возможности:

1. **👥 100% ИИ-Экипаж (20-40 агентов за раунд)**:
   - В начале каждого раунда процедурно генерируется от 20 до 40 уникальных членов экипажа.
   - Сбалансированное распределение по всем отделам: **Командование** (Капитан, HoP, HoS, CE, CMO, RD), **СБ** (Офицеры, Смотритель, Детектив), **Инженерия** (Инженеры, Атмосферники), **Медблок** (Врачи, Химики, Вирусологи), **Наука** (Ученые, Робототехники), **Сервис** (Бармен, Шеф-повар, Ботаник, Уборщик, Клоун, Мим, Капеллан), **Карго** (Квартирмейстер, Грузчики, Утилизаторы).
   - Расы: Люди, Рептилоиды (Унатхи), Дионы, Слаймолюди, Моли (Никты), Дварфы.
   - **Абсолютное погружение**: Каждый персонаж свято верит, что он настоящий живой сотрудник корпорации Nanotrasen на борту станции в глубоком космосе.

2. **📋 Документы Восприятия (Sensory Perception Frames)**:
   - Агенты видят мир через специализированные структурированные документы:
     - **Руки и Экипировка**: Содержимое левой и правой руки, пояс, карманы, скафандр, ID-карта.
     - **Окружение**: Отсек, давление в кПа, температура, статус энергосети, повреждения обшивки.
     - **Люди рядом**: Кто находится в комнате, их раса, форма, предметы в руках, статус здоровья.
     - **Радиоэфир и Объявления**: Общий канал, каналы отделов, сирены тревоги, переговоры.
     - **Биометрия и Состояние**: Здоровье (100 HP), физический/ожоговый/токсический урон, настроение, стресс, внутренние мысли.

3. **🔪 Антагонисты Синдиката и Цели Станции**:
   - 2-5 членов экипажа тайно назначаются спящими агентами Синдиката.
   - Получают секретный PDA-апплинк, пароли, частоту связи, телекристаллы и covert-задачи:
     - *Ликвидировать Капитана и украсть антикварный лазер*;
     - *Выкрасть Диск Ядерной Аутентификации (Nuclear Disk)*;
     - *Саботировать энергосеть или атмосферные магистрали*;
     - *Сбежать живым на эвакуационном шаттле*.
   - Обычный экипаж выполняет цели станции: поддержание питания, синтез лекарств, лечение раненых, научные исследования, приготовление еды, патрулирование.

4. **🎬 Пульт Режиссера (Director Mode Web Deck)**:
   - Интерактивный веб-интерфейс в стилистике Nanotrasen OS:
     - **Живая карта станции**: Перемещение агентов по отсекам в реальном времени.
     - **Реестр экипажа**: Просмотр состояния любого агента, его мыслей и Документа Восприятия.
     - **Запуск катастроф в 1 клик**: Метеоритный дождь, перегрузка питания, вспышка вируса, солнечная радиация, появление аномалии, Хонк-фестиваль клоуна.
     - **Телепатическое внушение**: Прямая трансляция мыслей/голосов в голову любого персонажа.
     - **Управление уровнями тревоги** (Зеленый, Синий, Красный, Дельта) и эвакуационным шаттлом.

5. **🌐 Публичный доступ в Colab в 1 клик**:
   - Автоматическая интеграция **Playit.gg** (прямой UDP/TCP проброс для игрового клиента SS14).
   - Автоматический HTTPS-туннель **Cloudflared / Ngrok** для веб-пульта Режиссера.

6. **🧠 OpenAI-Совместимый Бэкенд**:
   - Поддержка OpenAI (`gpt-4o-mini`, `gpt-4o`), OpenRouter, DeepSeek (`deepseek-chat`), Groq, Ollama, LM Studio.
   - Встроенный отказоустойчивый эвристический ИИ-движок, позволяющий запускать симуляцию даже без API-ключа.

## 🚀 Быстрый старт в Google Colab

1. Откройте блокнот **[`Space_Station_14_AI_Server.ipynb`](Space_Station_14_AI_Server.ipynb)** в Google Colab.
2. Вставьте ваш `OPENAI_API_KEY` (или оставьте пустым для встроенного эвристического движка).
3. Нажмите **Среда выполнения ➔ Выполнить все** (Runtime ➔ Run all).
4. В финальной ячейке появится:
   - 🎮 **Адрес подключения для лаунчера SS14**: `ss14://<адрес>`
   - 🎬 **Ссылка на Пульт Режиссера**: `https://<случайный-домен>.trycloudflare.com`

## 💻 Локальный запуск (Local Execution)

### 1. Клонирование и установка зависимостей:
```bash
git clone https://github.com/howlol/ss144.git
cd ss144
pip install -r requirements.txt
```

### 2. Запуск всей системы:
```bash
python3 start_all.py --crew 30 --port 8000 --game-port 1212
```

Параметры запуска:
- `--crew <20-40>`: Количество ИИ-членов экипажа (по умолчанию: 30)
- `--api-key <key>`: Ключ OpenAI API
- `--base-url <url>`: URL эндпоинта (по умолчанию: `https://api.openai.com/v1`)
- `--model <name>`: Название модели (по умолчанию: `gpt-4o-mini`)
- `--port <port>`: Порт веб-дэшборда (по умолчанию: 8000)
- `--game-port <port>`: UDP-порт игры Space Station 14 (по умолчанию: 1212)
- `--enable-tunnels`: Включить Cloudflared / Playit туннелирование

### 3. Запуск тестов:
```bash
python3 -m unittest discover tests
```

## 🎮 Как подключиться к серверу Space Station 14

1. Скачайте и установите бесплатный официальный лаунчер **Space Station 14** с сайта [spacestation14.com](https://spacestation14.com) или из Steam.
2. Откройте лаунчер SS14 и перейдите во вкладку **«Прямое подключение» (Direct Connect)**.
3. Введите адрес сервера: `ss14://<ip_или_домен>:<порт>` (отображается в верхней строке Пульта Режиссера и в выводе блокнота Colab).
4. Нажмите **«Подключиться» (Connect)**.
5. Вы окажетесь на станции вместе с 20-40 ИИ-членами экипажа! Вы можете говорить с ними в микрофон/чат, получать лечение в медблоке, заказывать еду у шефа или расследовать диверсии Синдиката.

## 🏗️ Архитектура системы

```
ss144/
├── Space_Station_14_AI_Server.ipynb  # Мастер-блокнот Google Colab (все в одном)
├── start_all.py                      # Главный исполняемый скрипт
├── requirements.txt                  # Зависимости Python
├── ai_engine/
│   ├── crew_generator.py             # Генератор 20-40 уникальных ИИ-персонажей и предателей
│   ├── perception.py                 # Генератор Документов Восприятия (Sensory Frames)
│   ├── station_world.py              # Топология станции, физика, радио, цели, действия
│   ├── brain.py                      # OpenAI / LLM мозг с эвристическим фоллбэком
│   ├── director.py                   # Режим Режиссера, катастрофы, внушение мыслей
│   └── orchestrator.py               # Координатор циклов симуляции и синхронизации
├── ss14_server/
│   ├── server_manager.py             # Управление Robust.Server и server_config.toml
│   └── rcon_client.py                # RCON мост для трансляции радио и команд в игру
├── tunnels/
│   └── tunnel_manager.py             # Playit.gg, Cloudflared, Ngrok проброс портов
├── dashboard/
│   ├── app.py                        # FastAPI бэкенд и WebSocket шлюз
│   ├── templates/index.html          # Интерфейс Пульта Режиссера (Nanotrasen OS)
│   └── static/
│       ├── style.css                 # Стили киберпанк / SS14 HUD
│       └── app.js                    # Клиентская логика, карта, инспектор документов
└── tests/
    ├── test_simulation.py            # Модульные тесты генерации, мира, режиссера
    └── test_api.py                   # Тесты REST API и WebSocket эндпоинтов
```
